# Third-party notices

Version 1.0.0 does not bundle third-party runtime libraries. The module uses PrestaShop's pricing, translation and asset APIs and the Smarty installation supplied by the shop. Their versions and licenses are determined by the installed PrestaShop distribution; they are not redistributed in this module ZIP.

The browser script uses native DOM APIs and the PrestaShop event bus. There are no external API calls or CDN assets loaded by the module.

Playwright is used from the development workspace for browser tests. It is not included in the installable ZIP, and the tests directory is excluded from the archive.
